#Exoplanet Transit Detection Pipeline

This project builds a full pipeline for detecting and analysing exoplanet transits using real astronomical light curve data from NASA missions (Kepler / TESS).

#Objectives
- Load and preprocess stellar light curve data
- Detect periodic transit signals
- Estimate exoplanet parameters (orbital period, radius proxy)
- Validate detections using statistical methods

#Tools & Libraries
- Python (NumPy, SciPy, pandas, matplotlib)
- lightkurve
- astropy
- Jupyter Notebooks

#Project Structure
- notebooks/: step-by-step analysis
- src/: reusable Python modules
- results/: figures and outputs
- report/: final write-up (LaTeX)
